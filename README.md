# QShare — كيو شير

مشاركة ملفات بسيطة بين جهازين أندرويد، بدون إنترنت وبدون حساب.

الشاشة الرئيسية فيها **زرّان فقط**:

- **استلام**: اضغطه فيظهر رمز QR كبير فوراً.
- **إرسال**: اضغطه فتفتح الكاميرا، امسح رمز QR، اختر ملفاتك وأرسلها.

## كيف يعمل

1. الجهاز المستلم يضغط **استلام** — يبدأ سيرفر محلي صغير على المنفذ 8765
   ويعرض رمز QR فيه عنوان الجهاز ورمز سري مؤقت.
2. جهاز الإرسال يضغط **إرسال** ويمسح الرمز — مسح الرمز نفسه هو الإذن،
   فلا توجد نافذة "هل تقبل هذا الملف؟" لكل ملف.
3. تُفتح نافذة اختيار الملفات: صور وفيديو من المعرض، أو أي ملفات،
   أو **مجلد كامل** — يُضغط (zip) مع الحفاظ على بنيته وأسمائه،
   ويُنزل كاملاً في الجهاز الآخر.
4. الملفات المستلمة تُحفظ تلقائياً في مجلد **QShare**
   (`/storage/emulated/0/QShare`) الظاهر في مدير الملفات — وليس في التنزيلات.

## الأذونات (مرة واحدة فقط)

تُطلب كل الأذونات مرة واحدة عند أول تشغيل: الكاميرا (للمسح)، الصور
والملفات (للإرسال والاستلام)، الموقع والأجهزة القريبة (لاكتشاف الجهاز
الآخر — التطبيق لا يعرف مكانك ولا يحفظه)، والوصول لكل الملفات
(لحفظ الملفات في مجلد QShare العام). بعد الموافقة لا يسألك التطبيق
عنها مرة أخرى. بدون إذن الوصول الكامل تُحفظ الملفات في مجلد
التطبيق الخاص ويوضح التطبيق ذلك في الشاشة الرئيسية.

## الاتصال

الجهازان على **نفس الواي فاي أو الهوتسبوت**. شاشة الاستلام تعرض عنوان
الجهاز. لا حاجة للإنترنت. زر "فتح مجلد QShare" ينسخ مسار المجلد لتفتحه
من مدير الملفات.

> **Wi-Fi Direct غير مطبق بعد (المرحلة 2):** النقل حالياً عبر نفس
> الواي فاي أو الهوتسبوت فقط.

## البناء

```sh
flutter pub get
flutter analyze   # 0 issues
flutter test      # اختبارات: QR، ضغط/فك مجلد، نقل كامل (ملف + مجلد)
flutter build apk --release
```

- Flutter 3.50.0 / Dart 3.14.0، Java 17، Android SDK 36
- `minSdk 24`، `compileSdk`/`targetSdk 36`
- الحزمة: `com.qshare.app`، الإصدار 1.0.0
- `permission_handler` 12.0.1 (الإصدار 13 يتطلب SDK 37 غير المتوفر بعد)
- نسخة الإصدار موقعة بمفتاح debug الافتراضي من قالب Flutter (مناسبة
  للتثبيت المباشر، وليست للنشر على المتجر)

## الخصوصية

لا حساب، لا سحابة، لا تتبع. الملفات تنتقل مباشرة من جهاز لجهاز
على الشبكة المحلية فقط، والرمز السري المؤقت يُتحقق منه في كل رفع.
